==================================================
C IO 定石ドリル集・README2（第2章）
========================

前提：

- 構造体禁止
- ヒープ禁止（mallocなし）
- I/Oは広く解禁
  fopen / fclose
  fgetc / fgets
  fputc / fputs / fprintf
  fscanf / sscanf
  fseek / ftell / rewind
  fread / fwrite
  feof / ferror / clearerr
  perror / strerror

目的：

- fscanf / sscanf を安全に扱う
- fgets → sscanf の実務パターンを体に入れる
- fseek / ftell によるカーソル制御を理解する
- r+ / w+ / a+ の挙動を実験で理解する
- feof / ferror / clearerr の違いを理解する
- fread / fwrite を配列レベルで扱えるようにする

※構造体・ヒープは使用禁止

---

## 共通ルール（全問）

A) すべてのプログラムは「成功時 return 0」「失敗時 return 2」
B) 失敗時は perror または fprintf(stderr, ...) を出す
C) 読み込みループ後は必要に応じて ferror を確認する
D) fclose の失敗も（最低でも perror）確認する
E) “何を失敗とみなすか” を問題文の完了条件に従って固定する

==================================================
Level 4：フォーマット入力（行パース中心）
========================

16. 整数を順に読む（fscanf）

入力例：
10
20
30

完了条件：

- 入力中の整数をすべて合計して標準出力に1行で出す（例：60）
- EOFによる終了と「フォーマット崩れ（数値でない）」を区別する
  - フォーマット崩れが起きたら return 2
  - EOFで正常終了なら return 0

---

17. fgets → sscanf 基本CSV（失敗行が出たら停止）

入力例：
10,20
30,40

完了条件：

- 行ごとに読み、各行が `整数,整数` の形式であることを検証する
- すべての行がパース成功なら、成功行数を出力して return 0
- 1行でもパース失敗したら、その時点で return 2
- （任意だが推奨）失敗した行番号を stderr に出す

---

18. 幅制限付き文字列（sscanf）

入力例：
alice 18
bob 100

完了条件：

- 各行が「名前（空白なし） + 空白 + 整数」の形式であることを検証する
- 名前の読み取りには **幅制限付き %s** を使い、バッファ破壊しないこと
- すべての行が成功したら成功行数を出力して return 0
- 1行でも失敗したら return 2

※注意：名前が長すぎる行があっても “クラッシュしない” のが合格条件の一部

---

19. %n を使ったゴミ検出（厳密CSV）

入力例：
10,20
30,40xyz
50,60

完了条件：

- 各行が「整数,整数」以外の余計な文字を含む場合は失敗扱いにする
  （末尾の空白・改行は許可）
- 失敗行が出たら return 2（行番号を出せると良い）
- 全行成功なら成功行数を出力して return 0

---

20. 空行スキップ

入力例：
(blank)
(空白だけ)
10,20

完了条件：

- 空行、および空白だけの行は **スキップ**して処理対象外とする
- それ以外の行は 17 または 19 と同等のルールでパースする
  （どちらの厳密さにするかは決めてコメントに明記）
- パース失敗行が出たら return 2
- “処理したデータ行数（空行除外）” を出力して return 0

---

21. 1行に複数整数（最大3個）

入力例：
1 2 3
10 20
7

完了条件：

- 各行について「1〜3個の整数」が読める場合のみ成功
- 0個（空行）や、整数以外のゴミが混ざる行は失敗（return 2）
- 各行の合計を `line N: SUM` 形式で出力（Nは1始まり）
- 全行成功で return 0

==================================================
Level 5：fscanf 戻り値地獄
====================

22. fscanf CSV版（厳密判定）

完了条件：

- `while ((rc = fscanf(...)) == 2)` の形式で読む
- ループ終了後に以下を区別する：
  - rc == EOF かつ ferrorなし → 正常終了（return 0）
  - ferrorあり → read error（return 2）
  - rc != 2（0や1など）→ フォーマット崩れ（return 2）

- 読めたレコード数を出力する

---

23. %\* 抑制（2列目だけ読む）

入力例：
10,20,30

完了条件：

- 2列目だけを読み取り、標準出力に出す
- フォーマット崩れ（列が足りない等）は return 2
- EOFは正常終了

---

24. 改行は区切りではないことを実証

入力例：
10 20
30

完了条件：

- `fscanf("%d")` で読んだ結果が「10, 20, 30」になることを出力で示す
- 出力に、改行が“区切り”にならない理由を短くコメントとしてコード内に残す
- 正常終了 return 0

==================================================
Level 6：ランダムアクセス（fseek / ftell）
===============================

25. ファイルサイズ取得

完了条件：

- ftellで取得したサイズ（バイト数）を出力
- 元の位置に戻して終了（rewindまたはfseekでOK）
- 空ファイルでも動く

---

26. 最後の1文字を表示（空ファイル対策込み）

完了条件：

- 空ファイルなら「empty」と出して return 0（メッセージは任意）
- 非空なら「最後の1バイト」を数値（0〜255）または文字で出力して return 0
- 範囲外fseekなどの異常は return 2

---

27. Nバイト目を表示（範囲外対策込み）

完了条件：

- N（例：100）バイト目（1始まり/0始まりはどちらでも良いが明記）を取得して出力
- Nがファイル範囲外なら return 2
- 正常なら return 0

---

28. 10バイト目を書き換え（r+）

完了条件：

- 10バイト目（定義は明記）を書き換える
- 書き換え後、同じ位置を読み直して `'X'` になっていることを確認して出力
- 範囲外なら return 2
- 正常なら return 0

---

29. 逆順表示（1byteずつ）

完了条件：

- ファイル内容を末尾から先頭へ1バイトずつ逆順に出力
- 空ファイルでも落ちない
- read error は return 2

==================================================
Level 7：モード（r+ / w+ / a+）
=========================

30. r+ の上書き確認

完了条件：

- 先頭3文字を上書きし、ファイルサイズが変化しないことを示す
  （例：書き換え前後でサイズを表示）
- 正常終了 return 0

---

31. w+ のtruncate確認

完了条件：

- w+ で開いた直後にサイズが 0 であることを示す
- 何か書いた後にサイズが増えることを示す
- 正常終了 return 0

---

32. a+ の強制追記

完了条件：

- fseekで先頭に移動してから書いても、実際には末尾に追記されることを示す
  （例：書き込み後のファイル全体を表示 or サイズ変化を表示）
- 正常終了 return 0

---

33. 読み→書きのカーソル位置確認（r+）

完了条件：

- 数文字読んだ後に書き込み、どの位置が上書きされたかを出力で示す
- 正常終了 return 0

==================================================
Level 8：状態管理
============

34. while (!feof(fp)) の罠

完了条件：

- 同一ファイルに対して
  - `while (!feof(fp)) { c=fgetc(fp); ... }`
  - `while ((c=fgetc(fp)) != EOF) { ... }`
    の2方式を同一プログラム内で実行し、出力で差を示す

- feof方式では EOF を“データとして扱う”行（例：`-1`）が **ちょうど1回** 出ることを示す
- 正しい方式では EOF 行が出ないことを示す
- 正常終了 return 0（fclose確認）

---

35. EOF後にrewindだけで再読できるか

完了条件：

- EOFまで読んだ後に `rewind(fp)` し、同じ内容を再度読めることを出力で示す（前後一致が分かる形式）
- 正常終了 return 0（ferror/fclose確認）

---

36. clearerrを明示的に使う

完了条件：

- EOF到達後に `clearerr(fp)` を呼び、その後 `rewind(fp)` して再読できることを示す
- 35との差は「明示的に状態をクリアした」こと（例：`before/after feof` を出す）
- 正常終了 return 0（fclose確認）

---

37. 書き込みエラーを確認

完了条件：

- `fopen(...,"r")` の `FILE*` に `fprintf/fputc/fwrite` のいずれかで書こうとして失敗することを確認する
- 失敗を `perror` 等で出力し、return 0（“失敗を観測できたら成功”）
- fclose失敗も確認する

---

==================================================
Level 9：バイナリI/O（配列のみ）
=====================

38. バイト列コピー（fread/fwrite）

完了条件：

- 固定長バッファ配列で fread/fwrite し、入力をバイナリコピーする
- 成功時：コピー総バイト数を出力して return 0
- read error / write error は return 2（perror、ferror確認、fclose確認）

---

39. int配列保存・復元（固定長）

完了条件：

- `int a[100]` を fwrite し、rewind 後に `int b[100]` へ fread
- 全要素一致を検証し、一致ならOK出力して return 0
- 不一致やI/Oエラーは return 2（perror等、fclose確認）

---

40. ファイル全体を固定長バッファに読み込む

完了条件：

- ftell等でサイズ取得し、固定長配列に “全量” 読める場合のみ成功
- サイズが固定長を超える場合は return 2
- 成功時は読み込んだバイト数を出力して return 0
- ferror/fclose確認

==================================================
チートシート（実装の型）
============

[1] fgets → sscanf（行パースの型）

- 目的：行境界を保って安全にパース
- ポイント：%s は必ず幅制限、戻り値で成功判定

型：

- fgetsで行取得
- sscanfでパース
- rc（変換成功数）で分岐
- 必要なら %n でゴミ検出

---

[2] %n による「末尾ゴミ」検出の考え方

- sscanf("%d,%d%n", ...) で n を得る
- line[n] 以降に空白以外があれば NG
- 末尾の改行や空白は OK とするのが定石

---

[3] fscanf ループの厳密判定

- while (fscanf(...) == expected_count) { ... }
- ループを抜けたら
  - EOFなのか
  - ferrorなのか
  - 変換失敗（rc==0や1）なのか
    を区別する

---

[4] fseek / ftell 基本（サイズ取得→戻す）

- fseek(fp, 0, SEEK_END)
- size = ftell(fp)
- rewind(fp)

注意：ftell は long を返すことが多い（環境依存）

---

[5] r+ / w+ / a+ の要点

- r+：サイズ維持、現在位置に上書き
- w+：truncate（0クリア）して先頭から
- a+：書き込みは常に末尾（fseekしても末尾に付く）

---

[6] feof の罠

- feof は「次の読みが失敗した後」に立つ
- while (!feof) は最後の1回で失敗データを処理しがち
- 正解は「読み取り関数の戻り値で回す」

---

[7] fread/fwrite コピーの型

- unsigned char buf[4096];
- while ((n = fread(buf, 1, sizeof buf, in)) > 0) {
  if (fwrite(buf, 1, n, out) != n) write error
  }
- ループ後に ferror(in) を確認
